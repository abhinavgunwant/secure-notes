# secure-notes

Work In Progress!

Secure notes is a note-taking app that encrypts your notes. Currently, only
plain text is supported with rich text support aimed at the Beta version.

You start by creating "Vault" which is a secure collection of notes. Each
vault can contain multiple secure notes and folders. You must setup a vault
with a password, each note inside that vault will be encrypted using that
password.

## Building

Development (Debug) build:
```bash
cargo build
```
